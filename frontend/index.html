Language model from Hugging Face GGUF, for llama.cpp

Paste the address of a model's page on huggingface.co – a repo with GGUF files, its name usually ends in -GGUF, e.g. https://huggingface.co/unsloth/Qwen3-4B-GGUF – then pick a file. A file's own page (…/blob/main/<file>.gguf), its download link (…/resolve/main/…) or hf.co/<owner>/<repo>:Q4_K_M work too. The original model repos (safetensors) don't. Every file is checked against Hugging Face's checksum; gated models (Gemma, Llama …) need HF_TOKEN in ai-serve.local.env.

Welcome to ai-serve

ai-serve is a gateway for local AI on this machine: language models, images, speech and documents behind one OpenAI-compatible API. Installed models load when a request needs them – the services behind them (speech, transcription, images) are started then too – and are unloaded again after a while unused or when the memory is needed elsewhere. Apps like the Spielwiese you start yourself, or let them start with ai-serve (Autostart).

1. Use it as an API

Any program that speaks the OpenAI API can use it -- point it at this base URL. model is a model's name, or default for the standard chat model.


            
Examples: curl and Python
                

                

            

            
Endpoints: /chat/completions, /embeddings, /rerank,
                /images/generations, /images/edits, /audio/speech,
                /audio/transcriptions, /models -- plus what is available right now:
                /llm/models, /images/models, /audio/models. Every endpoint with
                its fields: /docs (interactive).

            
Only this machine (and your own devices in a private network such as Tailscale) may use it.
                Other devices on your local network need a key: set LLAMA_SERVE_API_KEY (32+ characters) in
                ai-serve.local.env and send it as Authorization: Bearer ….


            
2. Try everything in the Spielwiese

            
The Spielwiese ("playground") is an app to try everything the gateway offers: chat, images, speech, comparing
                texts, reading documents. It runs as its own small app -- start it here and open it in a new tab.
